# MaktabOS

MaktabOS — o‘quvchilar, ustozlar va maktab boshqaruvi uchun akademik raqamli ekotizim.

## Frontend tuzilishi
- `index.html` — sahifa tuzilishi.
- `assets/css/styles.css` — dizayn, responsive layout va dark/light theme.
- `assets/app.js` — ilova logikasi va UI interaksiyalari.
- `favicon.svg` — loyiha belgisi.
- `manifest.webmanifest` — web app metama’lumotlari.

## Ishga tushirish
GitHub Pages yoki boshqa statik hosting orqali `index.html` faylini oching.

## Eslatma
Yangilanish frontend bilan cheklangan. Mavjud Firebase ulanishi va ma’lumotlar oqimi o‘zgartirilmagan.
